# Mô tả tóm tắt về website

Website bán hàng là một trang web chuyên cung cấp các sản phẩm quần áo thời trang cho nam, nữ và trẻ em, đồ điện tử. Website thường có đầy đủ các chức năng cơ bản như:
- Hiển thị thông tin: Website cần hiển thị đầy đủ và chính xác thông tin về sản phẩm như hình ảnh, mô tả chi tiết, giá cả, size, chất liệu,...
- Tìm kiếm sản phẩm: Website cần có chức năng tìm kiếm để giúp người dùng nhanh chóng tìm kiếm sản phẩm họ cần theo tên, loại sản phẩm, size, giá cả,...
- Giỏ hàng: Website cần có chức năng giỏ hàng để người dùng có thể thêm sản phẩm vào giỏ hàng, xem giỏ hàng và thanh toán.
- Tài khoản khách hàng: Website cần cho phép người dùng tạo tài khoản để lưu trữ  thông tin cá nhân, theo dõi đơn hàng và đổi trả sản phẩm.- Liên hệ: Website cần cung cấp thông tin liên hệ để người dùng có thể dễ dàng liên hệ với website khi cần hỗ trợ
